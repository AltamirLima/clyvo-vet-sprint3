# CLYVO VET — Sprint 3

Projeto acadêmico da disciplina Disruptive Architectures: IoT, IoB & Generative IA.

## Proposta

O CLYVO VET utiliza um Motor Inteligente baseado em regras parametrizadas para identificar obrigações de cuidado ao longo da jornada contínua do pet e apoiar a conversão de recomendações clínicas em ações para o tutor e a clínica.

> O protótipo não realiza diagnóstico veterinário. Perguntas clínicas devem ser direcionadas ao veterinário.

## Funcionalidades

- Dashboard com visão geral e itens que precisam de atenção
- Cadastro, consulta, busca e filtros de pets
- Demonstração do Motor Inteligente / IA
- Protocolos parametrizados com prioridade e explicação
- Arquitetura da solução e fluxo entre aplicação, API, banco e IA
- Catálogo de dados utilizados e finalidade de uso
- Jornada em 5 etapas: Prevista → Notificada → Respondida → Agendada → Cumprida

## Tecnologias

- HTML5
- CSS3
- JavaScript
- LocalStorage para persistência do protótipo
- SVG para identidade visual

## Como executar

Baixe ou clone o repositório e abra `index.html` em um navegador moderno. Não é necessário instalar dependências para executar a demonstração front-end.

## Estrutura

- `index.html` — interface principal
- `assets/app.js` — lógica da aplicação e motor de regras
- `assets/style.css` — estilos
- `assets/logo.svg` — identidade visual
- `docs/DOCUMENTACAO_IA.md` — especificação do componente de IA
